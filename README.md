# 🚀 HeadHunter Auto Response

## Описание проекта

**HeadHunter Auto Response** — современный и удобный инструмент для автоматизации откликов на вакансии на платформе HeadHunter. Проект помогает сократить время на рутинные задачи и сосредоточиться на важных аспектах поиска работы.

## 🚀 Быстрый старт

### Способ 1: Через веб-интерфейс (рекомендуется)

1. Откройте файл `index.html` в браузере
2. Настройте текст сопроводительного письма
3. Нажмите "Сгенерировать скрипт"
4. Скопируйте сгенерированный код
5. Откройте страницу с вакансиями на [hh.ru](https://hh.ru)
6. Откройте консоль браузера (F12 или Ctrl+Shift+I)
7. Вставьте скопированный код и нажмите Enter

### Способ 2: Через расширение Scripty

1. Установите расширение [Scripty для Chrome](https://chromewebstore.google.com/detail/scripty-javascript-inject/milkbiaeapddfnpenedfgbfdacpbcbam)
2. Используйте автоматическую установку: [Scripty Link](https://scripty.abhisheksatre.com/#/share/script_1727348873487)
3. Откройте страницу с вакансиями на hh.ru
4. Запустите скрипт через расширение

### Способ 3: Прямое использование (для разработчиков)

```javascript
// Скопируйте содержимое src/hh-automation.js
// Вставьте в консоль браузера на странице hh.ru
// Запустите:
const responder = new HHAutoResponder('Ваш текст письма');
responder.run();
```

## 📖 Подробная инструкция

### Настройка сопроводительного письма

В веб-интерфейсе введите ваш текст:

```
Добрый день!

Я заинтересован(а) в этой позиции и уверен(а), что мой опыт и навыки 
соответствуют требованиям вакансии. Буду рад(а) обсудить детали на собеседовании.

С уважением, [Ваше имя]
```

### Настройка задержек

Рекомендуемые значения:
- **Между откликами:** 1000-2000 мс (1-2 секунды)
- **Между действиями:** 500 мс
- **Ожидание модального окна:** 2000 мс
- **Загрузка страницы:** 4000 мс

### Чтение логов

После запуска скрипт выводит цветные логи в консоль:

- 📘 **Синий** — информация о процессе
- ✅ **Зеленый** — успешные действия
- ⚠️ **Желтый** — предупреждения
- ❌ **Красный** — ошибки

## ⚠️ Важные ограничения

### Не поддерживается:
- **Тестовые задания** — скрипт не может распознать и пройти тесты
- **Анкеты работодателя** — требуется ручное заполнение
- **Капча** — при появлении необходима ручная проверка

### Что делать при ошибках:

1. **Если вакансия требует тест:**
   - Добавьте её в чёрный список
   - Пройдите тест вручную
   - Перезапустите скрипт

2. **Если скрипт остановился:**
   - Проверьте консоль на ошибки
   - Обновите страницу
   - Запустите скрипт снова

3. **Если резюме не выбрано:**
   - Первый раз откликнитесь вручную с нужным резюме
   - После этого скрипт будет использовать последнее выбранное

## 🛠️ Для разработчиков

### Класс HHAutoResponder

```javascript
const responder = new HHAutoResponder(coverLetterText, {
    waitModalTime: 2000,          // Ожидание модального окна
    waitBetweenActions: 500,      // Задержка между действиями
    waitBetweenVacancies: 1000,   // Задержка между вакансиями
    waitPageLoad: 4000            // Ожидание загрузки страницы
});

// Запуск
await responder.run();

// Получение статистики
const stats = responder.getStatistics();
console.log(stats);
// {
//   processed: 50,
//   responded: 45,
//   skipped: 3,
//   errors: 2
// }
```

### Методы класса

- `run()` — запуск автоматизации
- `processVacancy(button, index, total)` — обработка одной вакансии
- `addCoverLetter()` — добавление сопроводительного письма
- `goToNextPage()` — переход на следующую страницу
- `getStatistics()` — получение статистики
- `stop()` — остановка работы

### Кастомизация

Вы можете расширить класс для своих нужд:

```javascript
class MyCustomResponder extends HHAutoResponder {
    async processVacancy(button, index, total) {
        // Ваша кастомная логика
        const result = await super.processVacancy(button, index, total);
        // Дополнительные действия
        return result;
    }
}
```
